# Repositório de Atividade

Repositório criado para a entrega da atividade, utilizando a estrutura base de um projeto anterior para agilizar o desenvolvimento.

## Arquitetura e Estrutura

O projeto segue o padrão **MVC** e está organizado nos seguintes diretórios:

* **`controller`**: Camada responsável por receber e responder às requisições.
* **`service`**: Camada que contém as regras de negócio da aplicação.
* **`repository`**: Camada de acesso e persistência de dados.
* **`model`**: Classes de domínio e entidades do sistema.
* **`exceptions`**: Tratamento de exceções personalizadas.
* **`util`**: Classes e métodos utilitários.
